# Problem Statement

- Find all the details possible of a given petrol pump. Google Maps, Provider Website, Reddit
- Find reviews of given petrol pump. Google Maps, Provider Website, Reddit
- To score the petrol pump on how good and well equipped it is?
- Review Filtering for exact and sensible reviews
- Give an overall score to the petrol pump, based on all the given metrics with a scoring mechanism.


# User Flow

- Text box to input. input can be a link, or location, or the petrol pump name
- Underlying ai agent api will search the web to find the link if not provided, and if provided, it'll hack into the right apis and get information.
- Structuring and filtering of relevant data intelligently 
- Overall review of the petrol pump, based on multiple factors like location, features


# Feature Extraction

- Petrol price compared to area average vs indian average
- Availability of refuling options. E5,E20, CNG
- Facilities available. Washroom, Air Refilling, etc
- Reviews
- Petrol Pump focused essentials like CCTVs,etc
- Location preference
- Quality of Life things - Payment methods, Parking, Store, Offers
